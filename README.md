# Locus

Local desk for things you already saved.

Needs Node 22.5+.

```bash
npm install
npm run dev
```

Open http://127.0.0.1:8787. Data stays in `~/Library/Application Support/Locus/locus.db` (macOS), `%APPDATA%/Locus` (Windows), or `~/.local/share/Locus` (Linux). Keep one process on port 8787.

More in [docs/BUILD.md](docs/BUILD.md).
